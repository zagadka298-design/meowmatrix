# 🐱 MeowMatrix

A cmatrix alternative with multi-color mixing and cat mode.

![Python](https://img.shields.io/badge/python-3.8+-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![PyPI](https://img.shields.io/badge/pypi-v2.1.0-orange)

## Features
- Multi-color mixing: meowmatrix red white blue
- Rainbow mode: all 7 colors
- Cat mode: meowmatrix meow (cats fall instead of chars!)
- White flickering heads like original cmatrix
- Config file + 3 charsets + zero deps

## Install
pip install meowmatrix

## Usage
meowmatrix
meowmatrix red white
meowmatrix rainbow
meowmatrix meow
meowmatrix --init

## Colors
red green blue cyan magenta yellow white rainbow meow
